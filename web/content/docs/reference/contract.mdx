## register_doc

```python
register_doc(title: str, clauses: list[str]) -> str
```

Store a document as numbered clauses. Its id is the hash of its text, so it can never be edited.

Refuses with:

- a document has … to … clauses
- the clauses are a list of texts
- this document is already registered as …

## challenge

```python
challenge(summary_id: int, claim_no: int, against: int, reason: str) -> int
```

Stake a tenth of the bond against one claim, optionally pointing at a second clause the claim is said to contradict (0 for none). Returns the challenge id.

Refuses with:

- a challenge stakes exactly … wei, a tenth of the bond
- the challenge window of this summary is over
- the document has no clause …
- this claim already has a challenge waiting to be read
- this claim was already …; a claim can be upheld once
- this summary has no claim …

## judge

```python
judge(challenge_id: int) -> str
```

Anyone asks the validators to read one claim against its clause. FAITHFUL is REJECTED and the stake goes to the author; MISSTATES and UNSUPPORTED are UPHELD and the stake comes back with 20% of the bond. Never moves money out of the contract.

Refuses with:

- this challenge was already read

## retract

```python
retract(summary_id: int, claim_no: int) -> int
```

The author strikes a challenged claim before it is read. The challenger gets the stake back plus 10% of the bond. Returns the challenge id.

Refuses with:

- only the author of the summary may retract a claim
- this claim has no challenge waiting to be read
- this summary has no claim …

## close_summary

```python
close_summary(summary_id: int) -> int
```

Anyone closes a summary whose window is over and has no open challenge: it STANDS, and the rest of the bond is credited to the author. Returns the amount credited.

Refuses with:

- the challenge window of this summary is still open
- this summary is already closed
- … challenge(s) still waiting to be read; read them first
