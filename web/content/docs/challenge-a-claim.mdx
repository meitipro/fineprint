On the site, open a summary, open the clause a claim cites, and press **Challenge this claim**. You choose a second clause if the claim contradicts another one, write a reason for readers, and sign. The price is shown first: the stake, and what you get if the claim is upheld.

<Steps>
<Step>

**Stake.** Exactly a tenth of the bond, sent with `challenge`.

</Step>
<Step>

**Read.** Anyone calls `judge`. The validators answer one label, FAITHFUL, MISSTATES or UNSUPPORTED.

</Step>
<Step>

**Settle.** The contract derives the verdict from the label and credits balances by rule.

</Step>
<Step>

**Withdraw.** The only call that pays is `withdraw`, in its own transaction.

</Step>
</Steps>

## Reading a summary

```js title="web/examples/read-summary.mjs"

import { createClient } from 'genlayer-js';
import { studioDevnet } from 'genlayer-js/chains';

const FINEPRINT = '0xe6Aa698d3b3c5F6ED7722f15649B0ca85EA7d092';
const chain = { ...studioDevnet, id: 61997, rpcUrls: { default: { http: ['https://studio-next.genlayer.com/api'] } } };

const client = createClient({ chain });
const [id = '1'] = process.argv.slice(2);
const s = JSON.parse(await client.readContract({ address: FINEPRINT, functionName: 'get_summary', args: [Number(id)] }));

if (!s.found) throw new Error('no such summary');
console.log(`#${s.id} ${s.doc_title}: ${s.state}, bond left ${Number(BigInt(s.bond_left) / 10n ** 15n) / 1000} of ${Number(BigInt(s.bond) / 10n ** 15n) / 1000} GEN`);
for (const claim of s.claim_rows) console.log(`  claim ${claim.no} (clause ${claim.clause}) ${claim.mark}: ${claim.text}`);
```

<Tab value="Python">

```python title="web/examples/read_summary.py"


import json
import sys

from genlayer_py import create_account, create_client
from genlayer_py.chains import studio_devnet

FINEPRINT = "0xe6Aa698d3b3c5F6ED7722f15649B0ca85EA7d092"
studio_devnet.rpc_urls = {"default": {"http": ["https://studio-next.genlayer.com/api"]}}

reader = create_account()
client = create_client(chain=studio_devnet, account=reader)
summary_id = int(sys.argv[1] if len(sys.argv) > 1 else 1)
s = json.loads(client.read_contract(address=FINEPRINT, function_name="get_summary", args=[summary_id], account=reader))

if not s["found"]:
    raise SystemExit("no such summary")
print(json.dumps({
    "document": s["doc_title"],
    "state": s["state"],
    "bond_gen": int(s["bond"]) / 10**18,
    "bond_left_gen": int(s["bond_left"]) / 10**18,
    "claims": [f'{row["no"]} (clause {row["clause"]}): {row["mark"]}' for row in s["claim_rows"]],
}, ensure_ascii=False))
```
